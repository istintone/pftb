| 2026-08-06 | **枠外とセーブから GK のフィードで再開するようにした**(→ [07. §7.18](07-match-engine.md)) | GKの3枚がほぼ死にデータだった(起点 0.27回/試合)。**その場で連鎖を回すのではなく、次の攻撃の入り口を予約する**形にした。即座に走らせた版は1ティックに攻撃が2回入り、得点が +44% 膨らんだ。予約に変えると攻撃の回数は 32.5回のまま動かず、GKのパスだけ 0.27 → 6.23本に増える。**ゴールキックは「攻撃が1つ増える」ことではなく「次の攻撃を誰がどこから始めるか」** |

| 2026-08-06 | ordtest のレーン検証を N=80 → **400** にした | 中央の効きは 6pp 前後だが、80試合(1300件)では 3〜6pp に振れてしきい値を割った。psotest・ordtest(采配)・traintest に続く**4件目の「測り方が系の変化に耐えられない」例** |
| 2026-08-06 | **連携に覚醒を足した**(→ [03. §3.31](03-game-design.md)) | 試合を重ねるだけで最上段に届くので、**交流を選ぶ理由が「少し早くなる」しか無かった**。合計160超で1/2の覚醒に挑め、成功すると黄金線(×1.10→×1.16)。**交流でしか越えられない線**を1本引くことで、1節を丸ごと使う価値を作る。失敗しても積み上げは消えないので、挑む側にリスクは無い |
| 2026-08-06 | 相手チームには連携を持たせない(保留) | 同じように積むと**先に相手の線が完成して一方的に不利**になる。こちらは昇降格や補強で顔ぶれが動くのに、相手は動かないため。後で固定値を与えるなどの形を考える |
| 2026-08-06 | 積み上がる速さは変えない | 貸与だけの編成では40試合で全組が最大段に届くが、これは**貸与が全員同じクラブで +1 が常時乗る**ため。手持ちを集めて好きな11人を組むほど国籍もクラブもばらけて +1 止まりの組が増える。**「好きな選手で組むと連携が育ちにくい」こと自体が交流を選ぶ理由**になっている |
| 2026-08-06 | **スキルの数値をグループの広さから決めるようにした**(→ [08. §8.6④](08-skills.md)) | W と S をフラットに置いていたので、**広いグループの札が狭いグループの札の4.8倍強かった**(origin)。`価値 = 発動率 × (S−1)` を層ごとに揃えると開きは 1.4倍に。狭いほど W も S も大きくなり、W型とS型の違いは**強さではなく形**(W型=よく来るが1回は薄い / S型=来ないが1回が厚い)になった。価値の合計は 955→948 と動かさず、公平化だけを行っている。careertest の「主効果があるなら s≤1.09」というフラットな規則は、**価値が目標±30%に収まっているか**という検算に置き換えた |
| 2026-08-06 | **W型とS型の対を6組そろえた**(→ [08. §8.6③](08-skills.md)) | `long` `wide` `carryOut` `press` `tec` `spd` にそれぞれ対を足し、「その手を**多用する**選手」と「その手が**上手い**選手」を別物にした。`press` だけは先にS型(タックル)があったのでW型(厳しい寄せ)を後から足している — **W型を先に置くと「荒い手を多用するが下手」という誰も選ばない札になる**。`pass` は起点の38%と広すぎるので埋めない |
| 2026-08-06 | 検証を**関係で測る**ように直した(traintest の絶好調) | 勝率の絶対値(>40%)で見ていたが、検証用クラブが低スコアだと引き分けが半分を占め、**勝36%/分52%/敗13%とはっきり勝ち越していても落ちた**。見るのは勝ちと負けの比。psotest(1人のGK)・ordtest(n不足)と同じ、**測り方が系の変化に耐えられなかった**例 |
| 2026-08-06 | **ポジションを問わない汎用スキルを6種足した**(→ [08. §8.4](08-skills.md)) | 掛かり先が「何をするか」ではなく**「どんな選手か」**(ケガ耐性・キャプテンシー・ムードメーカー・セットプレーの名手・スーパーサブ・鉄人)なので位置で分けない。これで**残る穴は連携だけ**になった。コンディションとケガは「不運の表現だから触らない」と決めていたが、**不運を消すのではなく振れ幅を縮める/確率を下げる**形なら引きの怖さは残るので方針を変えた。汎用は専門性ではないので **22%**(`TUNING.skill.any`)でしか引かせない —均等に混ぜると GK の実質プールが 9→15 になり、セービングが 33%→20% まで薄まって得点が増える |
| 2026-08-06 | **スキルを32種→42種に増やし、ポジション間のプールを揃えた**(→ [08. スキル](08-skills.md)) | GKが5種しか無く、**LEGENDSのGKは5種のうち4種(80%)**を持つのでどれも同じ札構成だった。9/11/12/12 に揃えて 44/36/33/33% にした。あわせてW型しか無かったグループにS型を対で足し(cross/passTec/cut/far/close)、その過程で**支配率・ブロック判定・ファウル**の3つの掛かり先が埋まった。コンディション・ケガ・連携は「不運」と「打ち手」の表現なので**意図的に残した** |
| 2026-08-06 | PKの `SET_FINISH.pk.k` を 1.62 → **2.50** に上げた(→ [08. §8.6](08-skills.md)) | 母集団のPK決定率が **44%** しかなかった。psotest が**同じクラブ同士**で回していて「そのクラブのGK1枚が何を引いたか」で決まっており、59% と表示されて帯を通っていた。相手を毎節変えて母集団を測るよう直したうえで、決定率 **73%**(現実は約75%)になる値へ。**1枚のカードで系を測る検証は、系が変わった瞬間に嘘をつく** |
| 2026-08-06 | **名声を順位から切り離し、評価と同じ表に相乗りさせた**(→ [03. §3.9](03-game-design.md)) | 評価を順位から外したのに名声だけが目標順位に張り付き、**目標が「お金」と「名声」を二重に動かして**いた。評価が上がる出来事は名声も生む(×40)、下がる出来事は名声を動かさない、の2ルールに統一。**名声が減ることもやめた** — 他人の私的な目標を外して世間の評判が落ちるのは筋が通らない。数値まで揃えなかったのは、評価が0〜100で頭打ち・名声が8,230まで積む必要があるため(揃えると1キャリア90で一生カンピオナート) |
| 2026-08-06 | **オーナーの評価を導出式から積み上げ式に戻し、目標順位と役割を分けた**(→ [03. §3.9](03-game-design.md)) | 導出式は「順位 = 評価」だったので、**格下相手に勝ち点を積んだ監督と格上を食って回った監督が同じ評価**になっていた。順位は目標(=お金)が引き受け、評価は「どう戦ったか」(格上に勝つ/タイトル/カップ初戦敗退)だけを見る。2026-07-31 に指摘した非対称は、**評価が順位から離れたことで前提ごと消えた** |
| 2026-08-06 | 「会長」を**オーナーに統一**した | 同じ人物を2つの呼び名で書いていて、評価の主体が2人いるように読めた |
| 2026-07-31 | オーナーの評価を**累積式から導出式に変更**(→ [03. §3.9](03-game-design.md)) | 累積式では `期待 − 順位` が、期待1位のクラブでは常に0以下・期待最下位のクラブでは常に0以上にしかならず、**上位クラブは評価が減る一方／下位クラブは決してクビにならない**という非対称が生じた(careertest が検出)。`基準値 + (期待 − 順位) × 係数` の導出にすると順位に依らず対称になる |
| 2026-07-31 | クラブの選手をセーブに持たず、シードから決定的に再生成する | 32クラブ×16人=512人をセーブに抱えると重い。`mulberry32(seed ^ hash(clubId))` で毎回同じ顔ぶれを再現できるため、保存が要るのは「集めたカード」と「貸与中の選手」だけで済む |
| 2026-07-31 | 就任時に名声0でも4クラブから選べるよう下駄を履かせた | 最初の就任先が1つしかないと、就任がただの通過儀礼になり「どのクラブを選ぶか」という判断が生まれない |
| 2026-07-31 | セーブキーを `pftb-save` にした | card-eleven(`ci-save`)と同一ドメイン(GitHub Pages のユーザーサイト)に置かれてもセーブが衝突しないため |
