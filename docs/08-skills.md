# 8. スキル

> 選手カードが持つ**スキル**の正本。設計の柱・全種の一覧・掛かり先の地図・**まだ穴の空いている場所**をまとめる。
> 追加を検討するときはここを見る。決定の経緯は [03. §3.21](03-game-design.md)、
> 掛かる先の仕組みは [07. 試合エンジン](07-match-engine.md)。

---

## 8.1 柱 — 1スキル = 1つの掛かり先

**スキルは試合エンジンの既存の判定に倍率を掛けるだけ。** 専用の分岐も専用のデータも作らない。
新しい効果が欲しくなったら、まず**エンジン側に掛かり先があるか**を確かめる(→§8.6)。

| 記号 | 何に掛かるか | 置き場 |
|---|---|---|
| **W** | その札を**引く重み**の倍率 | `SKILL_FX[name].w` |
| **S** | その判定の**スコア**の倍率 | `SKILL_FX[name].s` |
| **k** | 札を持たない層の単独の倍率 | `SKILL_FX[name].k` |

> **W と S は必ずセットにする。** 引きやすいだけでは成功率に繋がらず、何も強くならない。
> - W を持つスキルの S は控えめ(**×1.04〜1.08**) — 「その手を**多用し、少し上手い**」
> - S だけのスキルは強め(**×1.10〜1.30**) — 「その手が**明確に上手い**」
>
> この差が2つのスキルの性格を分ける。数字を決めるときは、まずどちらの性格かを決める。

`at2` を持つスキルは**2か所に掛かる**(例: 視野の広さ = 受け手に選ばれやすさ `k` + パス起点の S)。
1スキル1掛かり先の原則からは外れるが、**「動き出し」と「その結果」**のように
1つの資質が2つの判定に跨がるときだけ許す。現状は3種のみ(視野の広さ・ポストプレー・オフザボール)。

## 8.2 掛かり先の地図

1ティックの流れ(→[07. §7.5](07-match-engine.md))に沿って、どこに何が掛かるか。

```
 支配率(midPower) ─────────────── mid (セカンドボール / ビルドアップ k1.12〜1.15)
        │
 起点の選手を選ぶ ───────────────  start   (オフザボール k1.50)
        │                          vision  (視野の広さ k1.60 … 受け手の探し方)
 起点の札を引く ────────────────  origin W  (12種)
        │
 マッチアップ ─┬ 攻撃側スコア ───  origin S
                └ 守備側スコア ───  counter W/S (3種) / cover (カバーリング k1.45)
                                    marshal (守備の統率 k1.15 … GKが味方の寄せを厚くする)
                                    longStop (飛び出し判断 k0.92 … 相手の一発を摘む)
        │
 受け手を選ぶ ─────────────────  recv (ポストプレー k1.60)
        │
 (繰り返し = 連鎖)
        │
 終点の札を引く ────────────────  finish W/S (5種)
        │
 ブロック判定 ─────────────────  block (シュートブロック k1.18)
        │
 枠に飛ぶか ───────────────────  onTarget (フィニッシュ k1.12)
                                    offTarget (角度の消し方 k1.08 … GKが枠を狭める)
        │
 シュート vs GK ───────────────  finish S / gk (セービング k1.10)
                                    gkFin S (1対1の強さ … 終点の札で効きが変わる)
        │
 こぼれ球が出るか ──────────────  noRebound (反射神経 k0.65)
 こぼれ球を拾う ────────────────  rebound (詰めの速さ k1.15)

 [別系統]
 空中戦 ───────────────────────  aerial (空中戦 k1.15 / ハイボール処理 k1.12)
 PK ───────────────────────────  pkKick (PKの名手 k1.25) / pkGk (PKストップ k1.30)
 スタミナの消耗 ────────────────  stam (運動量 k0.80)
 ファウル・警告・退場 ──────────  clean (クリーンな守備 k0.70)
 ケガ ─────────────────────────  clean (同じ札。綺麗に止めれば相手も痛めない)
```

**`both`** は origin と counter の両方に掛かる指定。現状は「スピード」だけが使う
(速さは攻めるときも守るときも効く、という素直な表現)。

## 8.3 札のグループ

**新しいデータは持たせない。** 既にある札の属性から導く(`SK_GRP`)。

| グループ | 導出 | origin(39枚) | counter(39枚) | finish(39枚) |
|---|---|---|---|---|
| `pass` | `kind==="pass"` | 15 (38%) | — | — |
| `carry` | `kind==="carry"` | 22 (56%) | — | — |
| `passTec` | `pass` かつ `stat==="tec"` | **4 (10%)** | — | — |
| `long` | `to` を持つ(一発で前線へ) | 9 (23%) | — | — |
| `cross` | `lane==="box"` | 7 (18%) | — | — |
| `wide` | `lane==="out"/"switch"` | 9 (23%) | — | — |
| `cut` | `lane==="in"` | 8 (21%) | — | — |
| `carryOut` | `carry` かつ `lane==="out"` | 6 (15%) | — | — |
| `press` | `foul>=0.35`(荒い手) | — | 13 (33%) | — |
| `close` | `minH` を持つ(ゴール前限定) | — | — | 10 (26%) |
| `far` | `minH` を持たない | 39 (100%) | 39 (100%) | 29 (74%) |
| `spd` / `tec` | 札の `stat` | 13 / 12 | 12 / 13 | 13 / 13 |
| `all` | すべて | 39 | 39 | 39 |

> **`far` を origin や counter に使ってはいけない。** `minH` は終点の札しか持たないので、
> そこでは `far` が **100%** になり `all` と同じになる。狭く見えて実は最広という罠。

グループの広さは**Wの強さと釣り合わせる**。`passTec` は10%しか拾わないので W×1.70 でちょうどよく、
`carry` は56%も拾うので W×1.60 でも十分に効く(ドリブル)。**広いグループに強いWを付けない。**

## 8.4 一覧(42種)

数値は `SKILL_FX`。**W = 札を引く重み / S = 判定のスコア / k = 単独の倍率**。

### GK(9種)

| スキル | 掛かり先 | 効果 | 何が起きるか |
|---|---|---|---|
| セービング | `gk` | k×1.10 | 枠内シュートを止める力 |
| 反射神経 | `noRebound` | k**×0.65** | **こぼれ球そのものが起きにくい** |
| 飛び出し判断 | `longStop` | k×0.92 | 相手の一発(`long`)の守備スコアを上げる |
| PKストップ | `pkGk` | k×1.30 | PK の GK 側 |
| ハイボール処理 | `aerial` | k×1.12 | 空中戦 |
| 1対1の強さ | `gkFin` / `close` | S×1.16 | **ゴール前の終点に強い**(26%)。PKには掛からない |
| 角度の消し方 | `offTarget` | k×1.08 | 相手のシュートが枠を外れやすい |
| 守備の統率 | `marshal` | k×1.15 | **味方の寄せ**(`coverOf` の支援ぶん)が厚くなる |
| ビルドアップ | `mid` | k×1.15 | 後ろから組み立てて中盤の押し合いを助ける |

### DF(11種)

| スキル | 掛かり先 | 効果 | 何が起きるか |
|---|---|---|---|
| 対人守備 | `counter` / `all` | S×1.08 | 守備すべて。広いぶんSは控えめ |
| カバーリング | `cover` | k×1.45 | 守備の厚み(`coverOf`)。**寄せる範囲そのもの** |
| 空中戦 | `aerial` | k×1.15 | 攻守とも自分の側に効く |
| ロングパス | `origin` / `long` | W×1.70 S×1.06 | 一発で前線へ通す |
| オーバーラップ | `origin` / `carryOut` | W×1.70 S×1.05 | 外を持ち上がる |
| クロス | `origin` / `cross` | W×1.70 S×1.05 | エリアへ放り込む |
| スピード | **`both`** / `spd` | W×1.60 S×1.05 | 攻守どちらの `spd` 札にも |
| タックル | `counter` / `press` | S×1.12 | 荒い手が上手い。**勝つほどファウルとケガの入口も増える** |
| シュートブロック | `block` | k×1.18 | 身体を投げ出してコースを消す |
| クリーンな守備 | `clean` | k**×0.70** | **ファウルもケガも起こしにくい**(タックルの裏返し) |
| 正確なクロス | `origin` / `cross` | S×1.12 | 「クロス」(W型)の**対**。上げれば決まる |

### MF(12種)

| スキル | 掛かり先 | 効果 | 何が起きるか |
|---|---|---|---|
| スルーパス | `origin` / `passTec` | W×1.70 S×1.08 | いちばん狭いグループ(10%) |
| 視野の広さ | `vision` + `origin`/`pass` | k×1.60 / S×1.05 | **受け手を遠くまで探せる** + パス起点が上手い |
| キープ力 | `origin` / `carry` | S×1.08 | 持ち運びが上手い(引きやすさは変わらない) |
| ボール奪取 | `counter` / `tec` | W×1.60 S×1.06 | 技術で刈る守備 |
| ロングシュート | `finish` / `far` | W×1.70 S×1.06 | 遠めから狙う |
| ドリブル | `origin` / `carry` | W×1.60 S×1.05 | 持ち運びを多用する |
| 展開力 | `origin` / `wide` | W×1.70 S×1.05 | 逆サイドへ散らす |
| 運動量 | `stam` | k**×0.80** | 消耗が緩やか |
| PKの名手 | `pkKick` | k×1.25 | PK の蹴り手側 |
| セカンドボール | `mid` | k×1.12 | 中盤の押し合い(支配率)に効く |
| パスの精度 | `origin` / `passTec` | S×1.12 | 「スルーパス」(W型)の**対** |
| ミドルの精度 | `finish` / `far` | S×1.12 | 「ロングシュート」(W型)の**対** |

### FW(12種)

| スキル | 掛かり先 | 効果 | 何が起きるか |
|---|---|---|---|
| 決定力 | `finish` / `all` | S×1.10 | 終点すべて。広いのでWは持たない |
| フィニッシュ | `onTarget` | k×1.12 | **枠に飛ぶ率** |
| ポストプレー | `recv` + `origin`/`carry` | k×1.60 / S×1.05 | **預けられやすい** + 持ち出しが上手い |
| オフザボール | `start` + `origin`/`spd` | k×1.50 / S×1.05 | **起点に選ばれやすい** + 速さの札が上手い |
| ドリブル突破 | `origin` / `carry` | S×1.10 | 持ち運びが**明確に**上手い |
| カットイン | `origin` / `cut` | W×1.70 S×1.06 | 中へ切れ込む |
| ゴール前の嗅覚 | `finish` / `close` | W×1.70 S×1.06 | ゴール前限定の終点 |
| 詰めの速さ | `rebound` | k×1.15 | こぼれ球を拾う |
| スピード | **`both`** / `spd` | W×1.60 S×1.05 | DFと共有 |
| 空中戦 | `aerial` | k×1.15 | DFと共有 |
| 冷静なフィニッシュ | `finish` / `close` | S×1.12 | 「ゴール前の嗅覚」(W型)の**対** |
| 切れ込みの鋭さ | `origin` / `cut` | S×1.10 | 「カットイン」(W型)の**対** |

**複数ポジションに出るのは「スピード」「空中戦」の2種だけ。** 残り30種は1ポジション専用。

## 8.5 配り方

カード生成時に、**そのカードのメインポジションのプールから**段ごとの枚数だけ重複なく引く
(`cards.js` の `makeCard`)。

| 段 | 枚数 | GK(9種) | DF(11種) | MF/FW(12種) |
|---|---|---|---|---|
| STANDARD | 1 | 11% | 9% | 8% |
| REGULAR | 2 | 22% | 18% | 17% |
| SPECIALS / WORLD CLASS | 3 | 33% | 27% | 25% |
| LEGENDS | 4 | **44%** | 36% | 33% |

> **プールを揃えたのは、段の意味をポジションで変えないため**(2026-08-06)。
> GKが5種しか無かった頃は **LEGENDS のGKが5種のうち4種(80%)** を持つので、
> どのLEGENDS GKもほぼ同じ札構成だった。FW は10種から4種(40%)で個体差が出ていた。
> いまは 44% / 36% / 33% とほぼ揃っている。

## 8.6 埋めた穴と、残っている穴

2026-08-06 に **32種 → 42種**へ増やした。順番は **①プールの偏り → ③W型とS型の対**で、
その過程で**②の穴が3つ埋まった**(狙って足したのではなく、①③の掛かり先を探した結果そこに行き着いた)。

### ① ポジション間のプールの偏り — **解消済み**

| ポジション | 種類数 | LEGENDS が持つ割合 |
|---|---|---|
| GK | 5 → **9** | 80% → **44%** |
| DF | 8 → **11** | 50% → **36%** |
| MF | 9 → **12** | 44% → **33%** |
| FW | 10 → **12** | 40% → **33%** |

> **GKを増やすときは「PKに触らない」ものを選ぶ。** 最初に組んだ4種のうち
> 「シュートの読み」を `gkFin`/`far` にしたところ、**PKは `minH` を持たないので far に入り**、
> すべてのPKにGKのボーナスが掛かった。いまの4種(1対1の強さ=`close` / 角度の消し方=`offTarget` /
> 守備の統率 / ビルドアップ)は**どれもPKに掛からない** — PKは `fixAcc` で枠内が決まるので
> `offTarget` を素通りし、`close` は false になる。

### ② スキルが1つも掛かっていない局面 — **3つ埋まった**

| 局面 | いまの決まり方 | 状態 |
|---|---|---|
| ~~支配率~~(`midPower`) | MF の tec/spd/sta の合計 | **埋**: `mid`(セカンドボール / ビルドアップ) |
| ~~ブロック判定~~(`resolveBlock`) | 攻: tec/atk、守: def/pow × 人数 | **埋**: `block`(シュートブロック) |
| ~~ファウル・警告・退場~~ | 札の `foul` と `TUNING.foul*` | **埋**: `clean`(クリーンな守備) |
| **ケガ**(→[03. §3.32](03-game-design.md)) | マッチアップに負けた瞬間、守備側の札の反則率に比例 | `clean` が**間接的に**下げる。専用の札は無い |
| **コンディション**(→§3.32) | スタッツと乱数 | 残 — 「プロ意識」(下振れしにくい) |
| **連携**(→§3.31) | 試合と交流で積む | 残 — 「リーダーシップ」(積みが速い) |
| **セットプレーの蹴り手の質** | `spKicker` は能力だけで選ぶ | 残 — 「セットプレーの名手」 |
| **交代で入った直後** | スタミナ満タンなだけ | 残 — 「ジョーカー」 |

> **残した4つは意図的。** コンディションとケガは「不運」の表現なので、そこにスキルを足すと
> **不運が薄まる**。連携は打ち手(交流)で積むものなので、スキルで速めると打ち手の価値が下がる。
> 穴を埋めること自体は目的ではない。

### ③ W型とS型の対 — **5組そろえた**

| グループ | W型(多用する) | S型(明確に上手い) |
|---|---|---|
| `carry` | ドリブル | ドリブル突破 / キープ力 |
| `cross` | クロス | **正確なクロス** |
| `passTec` | スルーパス | **パスの精度** |
| `cut` | カットイン | **切れ込みの鋭さ** |
| `far`(終点) | ロングシュート | **ミドルの精度** |
| `close`(終点) | ゴール前の嗅覚 | **冷静なフィニッシュ** |

**まだ対になっていないグループ**: `long`(ロングパス) `wide`(展開力) `carryOut`(オーバーラップ)
`press`(タックル=S型のみ、W型が無い) `tec`(ボール奪取) `pass`(視野の広さ)。

### ④ グループの広さと W の段差 — **未着手**

`origin` の W はいまも **1.60〜1.70** に固まっている。狭いグループ(`passTec` 10%)と
広いグループ(`carry` 56%)で同じ強さなので、**狭いほど強く**する余地は残っている。
ただし現状のバランスはこれで取れているので、**動かすなら必ず実測してから**。

### 追加時に実測したこと(2026-08-06)

**枚数を増やすと、既存の1枚が出にくくなる。** これが balance を動かす主因で、
新しいスキルの効果そのものより大きい。

| | 変更前 | 変更後 |
|---|---|---|
| PK戦の決定率(母集団 400試合) | 49% | 44% |
| うち**新スキルの効果**による低下 | — | わずか1pt |
| うち**枚数の希釈**による低下(決定力・PKの名手が出にくい) | — | 4〜5pt |
| 1試合の得点 / 引き分け | — | **2.75〜2.81点 / 23%**(帯の内側) |

- リーグのバランスは**動いていない**(2.4〜3.2点・20〜27%引き分けの内側)
- PKだけ帯を外れたので `SET_FINISH.pk.k` を **1.62 → 2.50** に上げ、**決定率 73%**(現実は約75%)にした

> **そもそも 49% だったことに気付いていなかった。** psotest が
> **同じクラブ同士**で回していて、決定率が「そのクラブのGK1枚が何を引いたか」で
> 決まっていたため、59% と表示されて帯(55〜92%)を通っていた。
> 相手を毎節変えるようにして、母集団を測るように直した。
> **1枚のカードで系を測る検証は、系が変わった瞬間に嘘をつく。**

> ordtest も同じ理由で n=1000 では足りなかった。采配の差は 0.03〜0.09点で
> 標準誤差(±0.03)に埋もれ、**向きが反転して落ちた**。n=6000 にすると
> 攻撃 1.26得/1.11失・指示なし 1.08/1.02・守備 1.04/0.93 と安定して分かれる。

## 8.7 追加するときのルール

新しいスキルは、次を**すべて**満たすこと。

1. **`SKILLS` と `SKILL_FX` の両方に足す。** 片方だけだと静かに死ぬ
   (`skillsOf` が `SKILL_FX` を引けないスキルを黙って捨てる)
2. **掛かり先がエンジンに既にある**か、無いなら**先にエンジンへ `skK`/`skW`/`skS` を1行足す**。
   スキルのためだけの分岐は作らない(→[07. §7.1](07-match-engine.md))
3. **`grp` は既存の札の属性から導く。** 新しいフラグを札に持たせない
4. **W型かS型かを決める。** W を付けるなら S は 1.04〜1.08、S だけなら 1.10〜1.30
5. **グループの広さを確かめる**(§8.3の表)。広いグループに強いWを付けない
6. **ポジションのプールの大きさ**を見る(§8.5)。少ないポジションほど1種の重みが大きい
7. **プールが増えると既存の1枚が出にくくなる。** 効果そのものより、この希釈のほうが
   バランスを動かす。足したら `python build.py` → 8スイート →
   **母集団での実測**(得点・引き分け・PK決定率)まで見る(→§8.6 の実測)
8. **GKに足すときは「PKに触らないか」を確かめる。** PKは `fixAcc` で枠内が決まり
   `minH` を持たない。`far` や `tec` のグループは**PKも拾ってしまう**
