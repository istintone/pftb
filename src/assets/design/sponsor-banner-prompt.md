# スポンサーの看板 — 作成依頼（Gemini 向け）

契約中のスポンサー（→[docs/03 §3.40](../../../docs/03-game-design.md)）の**ピッチ脇の広告板**を作る。
HOME の次戦タイルと、キックオフの演出に出す。

| | |
|---|---|
| 作るもの | 横長の広告板（LEDボード / A看板）**1社につき1枚** |
| 会社 | **23社すべて架空**。実在の企業・商標を想起させるものは不可 |
| 出る場所 | HOME の次戦タイル（幅350px前後）／ キックオフのカットイン（全幅） |
| 出る大きさ | **横 350〜390px、縦 55px 前後**。かなり小さく縮む |

> **いちばん大事なのは「縮めても社名が読めること」。** 絵の作り込みではない。
> 実際に出るのは名刺より小さいので、**社名の文字が板の高さの半分**を占めるくらいでちょうどいい。

---

## 前回までに分かっていること（他の素材で踏んだ失敗）

| 失敗 | ここでの対策 |
|---|---|
| 生成AIはキャンバスサイズを守らない（1260指定で1648が来る） | **受け取った画像を縦4等分**して切る。サイズではなく**割り付け**を守ってもらう |
| 日本語の文字が崩れる | 板の文字は**ラテン文字だけ**にする（下の表の綴りを使う）。実際のピッチ脇の看板もそうなっている |
| 実在のロゴが紛れ込む | **具体的に禁止するものを名指しする**（下記）。受け取ったら必ず拡大して確認する |
| 絵が細かすぎて縮めると潰れる | 要素は**社名＋図形1つまで**。写真的な描写や細い線を禁止する |
| 暗いUIに置くと沈む / 金色が主役と喧嘩する | **黒に近い地色と、山吹色（#E8B84B 前後）の大面積**を禁止する |

## 1. 依頼文（ここから下をコピーして渡す）

サッカーゲームに出てくる、**架空の企業のピッチ脇広告板**を作ってください。
実在する企業・ブランド・商標とは無関係の、完全に架空の意匠です。

### キャンバスと割り付け（厳守）

- 全体サイズ **横 1024px × 縦 640px**
- **上から順に4等分**し、**1段につき1社**の広告板を描く（1段 = 横1024 × 縦160）
  - 段1: y 0〜160 ／ 段2: y 160〜320 ／ 段3: y 320〜480 ／ 段4: y 480〜640
- **各段は端から端まで塗りつぶす**。段の外に余白・枠線・影・区切り線を作らない
- **段の境界をまたがない**。文字や図形が隣の段に入り込まないこと
- 4枚は**別々の会社**なので、地色も書体の雰囲気も**互いに似せない**

### 各段の中身

- 描くのは **社名の文字**と、**シンプルな図形マーク1つまで**。それ以外は描かない
- **社名の文字の高さを、段の高さの 45〜60%** にする（つまり 72〜96px）。これより小さいと読めない
- 社名は**指定したラテン文字の綴りのまま**。勝手に単語を足したり訳したりしない
- 図形マークは社名の**左**に置く。マークだけで意味が通る単純な形にする
- 上下左右に **8%（横82px / 縦13px）の余白**を空け、そこには何も置かない
  （画面に出すときに端を切るため）

### やってはいけないこと

- **実在の企業ロゴ・商標・スローガンを描かない。** とくに次は絶対に描かないでください
  - スポーツ用品メーカーの記号的なマーク（チェック印・三本線・三つ葉 など）
  - 実在する航空会社の尾翼の意匠、実在する自動車メーカーの円形エンブレム
  - 実在する銀行・保険・通信・配信サービスのマークや配色の組み合わせ
- 写真のような描写、細かい模様、細い線、影の付いた立体文字は使わない（縮めると潰れます）
- **地色に真っ黒（#000 付近）を使わない。** 暗い画面に置くので、板が消えてしまいます
- **山吹色〜金色（#E8B84B 前後）を大きな面積で使わない。** 画面の主役の色と喧嘩します
- 人物・実在の街並み・国旗は描かない

### 質感

- **平らな色面 + 太い文字**。実際のスタジアムのLEDボード、または塗装したA看板の見た目
- 色数は**2〜3色**まで。地色・文字色・差し色1つ
- 文字と地色の明暗差をはっきり付ける（明るい地に濃い文字、または濃い地に白い文字）
- 段ごとに会社の**格**が違います。次の指示に合わせてください

### 今回の4社

> ここに下の「会社の一覧」から4社ぶんを貼って渡す。1社につき次の3行を書く。
>
> ```
> 段1: NORD LAGER
>   格: 中堅（2段）— 落ち着いた企業らしい看板
>   会社: 北の国のラガービール。冷たい国の醸造所
> ```

### 格ごとの言い回し（依頼文にそのまま書く）

| 段 | 依頼文に書く一言 |
|---|---|
| 1 | **町の看板**。手作り感があってよい。塗装したベニヤ板や、印刷屋の作った幟のような雰囲気 |
| 2 | **中堅企業の看板**。落ち着いた企業らしい配色と書体 |
| 3 | **大企業の看板**。洗練された、余白の効いた構え |
| 4 | **国をまたぐ企業のLEDボード**。冷たく、精密な印象 |

> **格の差を「派手さ」で付けない。** 1段が地味で5段が派手、ではなく、
> 1段は**手が入っている**、5段は**手が入っていない（無機質）**という差にする。
> 名声を積むと付き合う相手が「遠く」なっていく、という筋（→docs/03 §3.40）を絵でも見せる。

## 3. 受け取ったあとの手順

1. **拡大して実在の意匠が混ざっていないか確認する。** 生成AIは学習した実在のマークを出しやすい。
   スポーツブランドの記号、円形の自動車エンブレム、既存の配信サービスの配色は要注意
   （`python tools/zoom_kit.py <シート>` で拡大できる）
2. **縮めて読めるか確認する。** 幅350pxに縮めて社名が読めなければ作り直し。
   ここを妥協すると、画面では「何か色のついた帯」にしかならない
3. シートを `src/assets/art/banner/` に置く（**素材はここ。直下に置くと元画像が index.html に埋まる**）
4. `python tools/slice_banner.py <シート> <id> <id> <id> <id>` で4段に切る
   （縦4等分 → 上下左右を少し詰める → 幅640のWEBPへ）
   - 書き出しは `src/assets/banner/<id>.webp`。**id はスポンサーの id と同じ**
   - 段数が4でないシートは `--rows=N` で指定する
5. `python build.py` で埋め込む。`ASSETS.banner["<id>"]` で引ける
