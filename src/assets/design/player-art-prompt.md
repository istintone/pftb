# 選手ピクセルアート — 作成依頼（Gemini 向け）

1選手につき **3枚セット** を1枚の画像に横並びで作り、あとからプログラムで切り出す。
card-eleven の作り方を踏襲しつつ、**3枚すべてを用途を分けて使う**のが pftb の違い。

| # | 名前 | 用途 | ポーズ |
|---|---|---|---|
| ① | **立ち絵** | 選手とのコミュニケーション・チャット | **全員同じ**（正面立ち） |
| ② | **プレイ絵** | 編成画面・カード・試合中 | **選手ごとに違う**（その選手を象徴するプレー） |
| ③ | **ゴールモーション** | 得点シーン・目的達成時 | **選手ごとに違う**（喜びの表現） |

> card-eleven は3枚のうち**試合風景の1枚しか使っていなかった**。pftb は3枚とも役割を与える。

---

## 前回の課題と、今回の対策

| 課題 | 対策 |
|---|---|
| 切り出すと**選手ごとにサイズが変わる** | **足元ラインと頭の大きさを数値で固定**する（下記の「サイズ基準」）。枠だけ指定しても揃わない |
| 3枚の**中心がずれて重なる** | セルの**中心 x 座標を明示**し、はみ出し禁止を明記 |
| 参考画像を渡すと**同じポーズしか描かない** | 参考は「**画風だけ**」と明言し、**ポーズの再現を禁止**。動詞リストから選ばせる |

---

## 1. 依頼文（ここから下をコピーして渡す）

プロのピクセルアートデザイナーとして、サッカーゲームの選手素材を作ってください。

添付の参考画像は **画風（等身・線の太さ・彩度・陰影の付け方・ドットの粒度）だけ**を合わせるためのものです。
**ポーズは絶対に真似しないでください。** 参考と同じ構えになったら失敗とみなします。

### キャンバス（厳守）

- 全体サイズ **横 1260px × 縦 500px**、余白なし（ぴったりこのサイズ）
- **3つのセル**に等分し、左から ①立ち絵 ②プレイ絵 ③ゴールモーション
  - セル1: x 0〜420　　中心 **x=210**
  - セル2: x 420〜840　中心 **x=630**
  - セル3: x 840〜1260　中心 **x=1050**
- 選手は**必ず各セルの中心 x に立たせる**。左右は中心から ±170px の内側に収める
- **セルの境界を越えない**（隣のセルに手足やボールがはみ出さない）
- **ガイド線・枠線・区切り線は描かないでください**。切り出したときに絵に混ざってしまいます

### サイズ基準（これが最も重要）

複数の選手を並べたときに背丈が揃っていないと素材として使えません。次を厳密に守ってください。

- **足元（接地している足の裏）を y=470 に置く**（3枚とも共通）
- **頭の高さ（頭頂から顎まで）を約 62px** にする。**これは3枚とも、どの選手でも変えない**
- 立ち絵（①）は直立なので **頭頂が y≒96**、全身 約374px（およそ6頭身）
- ②③は姿勢で頭頂の位置が上下してよいが、**頭の大きさは①と同じ**にすること
  （ジャンプする場合も足元が浮くだけで、頭の大きさは変えない）

> 「枠に収める」だけでは背丈が揃いません。**頭の大きさと足元の位置**を基準にしてください。

### 背景

- **背景は純白（#FFFFFF）のみ**。グラデーション・影・地面・ピッチ・観客は描かない
- 選手の輪郭の外に**灰色のにじみを作らない**（白背景を抜いて使うため）
- **サッカーボールだけ**、そのポーズに必要なら描いてよい

### ユニフォーム（架空のクラブのもの・重要）

このゲームのクラブはすべて架空です。**実在のクラブ・ブランド・スポンサーのものは一切使わないでください。**

- **実在のクラブエンブレム、実在のメーカーロゴ（スポーツブランドのマーク等）、
  実在企業のスポンサー名を描かない**
- 実在クラブを連想させる**配色そのままの組み合わせも避ける**
  （例: 赤×白で胸に大きな文字、といった特定クラブと同じ見え方）
- 代わりに、**それらしい架空の意匠**を入れてください。これがあると「本物のカード」に見えます

> **⚠ 見落としが起きやすい箇所**（実際に起きました）
> スポンサー名だけ架空にして、**クラブエンブレムを実在のまま残す**ことが多いです。
> エンブレムは **右胸・左胸・パンツの裾**の3か所に入りがちなので、**すべて架空の意匠**にしてください。
> 「実在のクラブのユニフォームを、スポンサーだけ架空にしたもの」は不可です。
> **エンブレムまで含めて架空のクラブのユニフォーム**にしてください。

| 場所 | 入れるもの |
|---|---|
| 胸の中央 | **架空のスポンサー名**。短い英字の造語（下のリストから、または同種の造語） |
| 胸のエンブレム | **架空のエンブレム**。盾・円・モノグラムなど幾何学的で小さいもの。実在クラブの紋章（動物・帆船・城・王冠の具象的な組み合わせ）を真似ない |
| パンツの裾 | エンブレムを入れるなら**胸と同じ架空の意匠**にする（ここの入れ替え忘れが多い） |
| 袖・襟 | 無地、または細いラインのみ。メーカーロゴは**描かない** |
| 背中・パンツ | 背番号を入れてよい |

架空スポンサー名の例（この中から選ぶか、似た響きの造語を作ってください）:

```
NORVIK / SOLARIS / VANTIA / KESTREL / AURELIA / MERIDIAN
LUMEN / ORFEO / BALTIQ / CASTELLA / VELTRA / HANSEA
```

**依頼時にこちらから「クラブ名・クラブカラー2色」を伝えます。** その色でユニフォームを作ってください。
色の指定が無ければ、選手の雰囲気に合う2色を選び、**どの色にしたか答えてください**。

### 3枚の内容

**① 立ち絵（左）— 全選手で同じポーズ**

正面向き・直立・両腕を自然に下ろす・足は肩幅。表情は無表情かわずかに口角を上げる程度。
**この1枚だけは全選手で完全に同じ構え**にしてください（並べたときに揃って見えるように）。
違うのはユニフォーム・髪・肌の色・体格だけです。

**② プレイ絵（中央）— その選手を象徴するプレー**

次の動詞リストから、**その選手に最も似合うものを1つ**選んでください。

```
シュート / ヘディング / ボレー / ドリブル突破 / カットイン / スルーパス
ロングフィード / クロス / トラップ / competing（競り合い）/ スライディングタックル
ブロック / インターセプト / セービング / パンチング / スローイング（GK）
```

- **参考画像のポーズは使わない**。上のリストから選び、その選手らしい角度・重心で描く
- ポジションに合ったものを選ぶ（GK にドリブルを選ばない、CB にシュートを選ばない、など）
- **3枚のうちで最も動きが大きい絵**にしてください

**③ ゴールモーション（右）— 喜びの表現**

次の型から、**②とは違う体の使い方**になるものを1つ選んでください。

```
両腕を大きく広げる / 片手で指を突き上げる / 拳を握って引き寄せる
膝でスライディング / エンブレムを掴んで掲げる / 静かに天を仰ぐ
腕を組んで不敵に立つ / 走りながら振り返る / 両手でハートを作る
```

- **②と同じ腕の使い方にしない**（両方とも右腕を上げる、などを避ける）
- 感情が伝わること。ただし顔の描き込みは参考画像と同じ粒度に留める

### 進め方

1. まず **どの選手を描くか聞いてください**
2. 選手名を伝えます。あわせて**架空のクラブ名とクラブカラー2色**も伝えます
3. 受け取ったら、**先に文章で案を説明**してください
   - 3枚それぞれのポーズ（②はリストのどの動詞、③はどの型か必ず明記）
   - 「その選手らしい理由」を一言
   - **ユニフォームの配色・胸のスポンサー名・エンブレムの意匠**
4. こちらが「開始」と伝えたら、はじめて画像を作ってください

## 2. 受け取ったあとの使い道（依頼先には不要）

- 置き場所: `src/assets/players/<選手id>.png`（1200×500 の3枚セットのまま）
- 切り出しは **x=0/420/840 から幅420** で機械的に行う。個別に位置合わせしない前提なので、
  **依頼時のサイズ基準が守られているかを必ず確認する**（足元 y=470 / 頭の高さ 62px）
- **実在のロゴ・エンブレムが紛れ込んでいないか必ず確認する**（生成AIは学習した実在の意匠を
  出しやすい）。**スポンサーだけ架空にしてエンブレムが実在のまま**という取りこぼしが起きたので、
  **右胸・左胸・パンツの裾**を必ず拡大して見る。混ざっていたら描き直しを依頼する
  （確認用: `python tools/zoom_kit.py <シート> ` で胸元を拡大表示できる）
- 白背景の抜きと正規化は **`python tools/slice_player.py <シート> <選手id>`** で行う
  （3等分 → 縁からの白を透過 → 囲まれた背景も純白率で判別して除去 → 420x500 に統一）
- 輪郭に灰色のにじみがあると抜きが汚くなるため、受け取った時点で**輪郭の周囲を拡大して確認**する
- カード上では **②プレイ絵** を使う（`.pc-art` の枠）。①は会話、③は得点演出。
- ピクセルアートなので、拡大時は `image-rendering: pixelated` を必ず指定する

### ポーズの記録（被り防止）

**描いた選手ごとに、選んだ動詞と型をここに追記する。** 次の依頼時にこの表を見せて
「ここにあるものは避けて」と伝えると、ポーズの重複を防げる。

| 選手 | 架空クラブ / 配色 | ② プレイ絵 | ③ ゴールモーション |
|---|---|---|---|
| （例）A. シルヴェイラ | カサブランカ・ユニオン / 朱×白 | ボレー | 両腕を大きく広げる |
| C. ロナウド | マンチェスター・レッズ / 赤×白 | ドリブル突破 | 膝でスライディング（＋両腕を広げる） |

> ロナウドの回で分かったこと: スポンサー（AETHERNET / KINETICA）は架空に差し替わったが、
> **胸とパンツのエンブレムは実在のまま残った**。上の警告文はその実例。
> 現物は縮小すると潰れて判別できない大きさだったため、この1枚はそのまま採用している。
