# 選手カード 背景レイアウト — 作成依頼（Gemini 向け）

カードは**3層**で構成し、**レアリティを表現するのは一番下の「背景レイアウト」だけ**。
ここで依頼するのはその背景レイアウト（レアリティ4種）で、**文字と数字は一切描かない**。

| 層 | 中身 | レアリティで変わるか |
|---|---|---|
| ① 最前面 | 名前・OVR・能力値・ポジション・スキル等、**すべての文字と数値** | **変わらない**（CSSで描画） |
| ② 中間 | **選手のイラスト**（ピクセルアート） | **変わらない** |
| ③ 最背面 | **カードの背景レイアウト** ← 今回つくるもの | **これがレアリティを示す主役** |

> WCCF と同じ方式。通常は白い地、強いレアは黒い地、上位はホログラム、最上位は特別な版面。
> card-eleven も同様で、そこにスマホ向けのホロ表現をマスクで足している。
> 本作もこれに倣う。**動くホロ表現は実装側（CSS）で足す**ので、背景は静止画でよい。

> 前回いただいた [card-mock-v1.png](card-mock-v1.png) は**完成イメージ**として非常に良かった。
> 今回はそこから**文字と選手を抜いた「版面だけ」**を作ってもらう。

---

## 1. 依頼文（ここから下をコピーして渡す）

スマートフォン向けサッカーゲーム「P-footBall」の、**トレーディングカードの背景（版面）**を作ってください。

このカードは、あとから**選手のイラストと、すべての文字・数字をプログラムで重ねます**。
そのため背景には**文字も数字も一切描かないでください**。数値を置くための**枠や区画だけ**を用意します。

### 作品のトーン

- 暗色の盤面にゴールドを効かせた、モダンで落ち着いたサッカーゲーム
- コレクタブルカードとしての**格**を、地の質感と枠の作り込みで表現する
- レトロゲーム風の装飾過多にはしない。線は細く、面で見せる

### 出力してほしいもの

**背景4種を、横並びの比較シート**にしてください（各1枚ずつでも可）。

- カード1枚の比率 **3 : 4（縦長）**、推奨 750 × 1000 px
- シートの地は `#020306`
- **4種とも、区画の位置と大きさは1ピクセルも変えないこと**（同じ座標に文字を重ねるため）

### ⚠ ホログラム（虹の光沢）は描かないでください

**ホロの表現はすべてプログラム側（CSS）で後から載せます。**
画像に焼き込むと角度や解像度が固定されて質が落ちるためです。

- 虹色の光沢、斜めに走る光の帯、キラキラした反射は**一切描かない**
- 描くのは**地の色と質感、枠、区画**だけ
- 「光っている状態」ではなく「**光る前の素材**」を作るイメージ

## 2. 版面（4種で共通・ここは絶対に動かさない）

％はカード全体に対する比率。

```
┌──────────────────────────────┐
│ ▭                     ┌────┐ │  A: レア度プレート（左上）
│                       │ B  │ │  B: OVR 枠（右上）
│                       └────┘ │
│                       ┌────┐ │
│        (選手が        │    │ │  C: 能力欄
│         ここに        │ C  │ │     6行ぶんの区画
│         入る)         │    │ │     右端・下ぞろえ
│                       └────┘ │
├──────────────────────────────┤
│ D                            │  D: 名前帯（全幅・2行ぶん）
└──────────────────────────────┘
```

| 区画 | 位置とサイズ | 用意するもの |
|---|---|---|
| **A** レア度プレート | 左上。左端から 4%、上端から 3%。幅 42% × 高さ 6% | 文字が乗る小さな**帯や台座**。地より少し明るい/暗い面 |
| **B** OVR 枠 | 右端から 4%、上端から 3%。幅 26% × 高さ 15% | **大きな数字を置く枠**。ここが最も目立つ場所 |
| **C** 能力欄 | 右端から 4%。下端は名前帯の上 3% まで。幅 26% × 高さ 40% | **6行ぶんの区画**。行を分ける細い罫線か、行ごとの薄い帯 |
| **D** 名前帯 | 全幅。カード下端から高さ **18%** | **2行ぶんの地**。上辺に区切りの線 |
| **E** 外周の縁 | カードの外周 | **枠 + その内側にもう一本の細い縁線**（下記） |
| 選手が入る領域 | 左 66% × 上から 82% の範囲 | ここは**背景として静か**に。選手のシルエットが映えること |

### E. 外周の縁線（カードらしさの要）

トレーディングカードらしさは**外周の作り**で決まる。次の二重構造にする。

```
 ┌─────────────────┐ ← ① 外枠：カードの縁（レアリティの色・太さ 1〜2px相当）
 │ ┌─────────────┐ │
 │ │             │ │ ← ② 縁線：外枠の内側 4% に、もう一本の細い線
 │ │   カード面    │ │      （①と同系色で、より細く・控えめに）
 │ └─────────────┘ │
 └─────────────────┘
```

- ①と②の間は**地の色をそのまま**通す（余白として見せる）
- 格が上がるほど、この二重の縁が**厚く・密に**なる（LEGENDS が最も作り込まれる）
- 角は小さめの角丸（カード全体で 2% 程度）

- **B と C は右側の1本の列**としてまとまって見えること。列の背後は必ず暗くし、
  どんな選手の絵が来ても数字が読めるようにする。
- 選手は左寄せで入るので、**右 28% には選手が掛からない**前提。
- A・B・C・D 以外の場所に、文字が置けそうな枠を作らないこと（迷いのもとになる）。

## 3. 背景4種の作り分け（**差が出るのはここだけ**）

版面は同一のまま、**地の色と質感・枠の作り**で格の違いを出す。

ゲーム内のレアリティは5段だが、**背景は4枚**でよい。
`SPECIALS` は `REGULAR` と**同じ背景**を使い、差は**CSS の光沢**で付けるため。

| 背景 | 使うレアリティ | 地 |
|---|---|---|
| **1. 白** | STANDARD | 白 |
| **2. 黒** | REGULAR ／ **SPECIALS**（同じ背景を共有） | 黒 |
| **3. シルバー** | WORLD CLASS | 銀（クローム） |
| **4. 黒金** | LEGENDS | 黒 + 金 |

### 1. 白（STANDARD — 控え。クラブにはいるがレギュラーではない）

- **白〜淡いグレーの紙のような面**。マット（つや消し）
- 外枠は細いグレー `#88867f`。内側の縁線もグレーで、ごく控えめに
- 光沢・粒子は**一切なし**
- 能力欄と名前帯はごく薄いグレーの面で区切る
- ねらい: 「量産品のカード」。地味だが安っぽくはない

### 2. 黒（REGULAR — スタメン ／ SPECIALS — 切り札）

- **深い黒〜濃紺の面**。わずかに縦のヘアライン（金属を思わせる）
- 外枠は**銀** `#b9bec4` の細線。内側の縁線も銀で、外枠より細く
- 光沢・ホログラムは**入れない**（SPECIALS の「光り」はCSSで足す）
- ねらい: **白から黒への昇格**が一目で分かること。ここが最初の到達点

### 3. シルバー（WORLD CLASS — 世界的な名手）

- **銀（クローム）の地**。トレーディングカードのクローム仕様のような、
  金属を磨いた面。細かな縦のブラッシュ目があってよい
- **虹色は使わない**（虹のホロはCSSで載せる）。あくまで**無彩色の銀**
- 外枠は明るい銀 `#d8dce2` の二重線。内側の縁線もはっきり出す
- 能力欄・名前帯は銀地より一段暗いグレーで沈める（文字が乗るため）
- ねらい: **金属そのもの**。この上に虹が走ったときに最も映える下地であること

### 4. 黒金（LEGENDS — 伝説の名選手）

- **最高級**。4種の中で最も作り込む
- **深い黒地に金**。金の箔押し・金の細密な線。虹は使わない
- 外枠は金 `#e0af3b` の二重線 + 箔押しのような立体感。
  内側の縁線も金で、**4種の中で最も厚く密**に
- OVR 枠（B）の周囲だけ、装飾的なあしらいを許す（ただし**枠の位置は動かさない**）
- 中央の選手領域は空けたまま
- ねらい: **殿堂入りの重み**。**黒と金だけで最上位だと分かる**こと

---

## 4. やらないこと

- **文字・数字を一切描かない**（アルファベットも日本語も、ダミーの数字も禁止）
- **ホログラム・虹色の光沢・斜めに走る光の帯・キラキラした反射を描かない**（CSSで載せる）
- 選手・人物・シルエットを描かない（あとから重ねるため）
- 実在のクラブ・リーグ・ブランドのロゴやエンブレムを出さない
- 4種で**区画の位置や大きさを変えない**（変えると文字がずれる）
- 中央の選手が入る領域を、模様や強い光で埋めない
- 写真的な素材感（革・木目・布のクローズアップ）にしない

## 5. 受け取ったあとの使い道（依頼先には不要）

- 4枚を `src/assets/carddesign/` へ `card-bg-std.png` / `-reg` / `-wc` / `-leg` の名前で置く。
  `build.py` の `window.ASSETS` に自動で載る（グループ名 = ディレクトリ名）。
  対応は `RARITY[段].bg` が持つ（**SPECIALS は `reg` を指す**）。
- **ホロは CSS 側で実装済み**（`holo-sheen` / `holo-rainbow` / `holo-gold`）。
  SPECIALS = 白い光沢、WORLD CLASS = 虹、LEGENDS = 金の光沢が周期的に流れる。
- **外周の縁線も現在は CSS で描いている**（暫定）。背景画像に縁が入ったら CSS 側は外す。
- **WORLD CLASS はテーマレアへ派生させる予定**（BANDIERA / MVP / BEST ELEVEN など）。
  そのとき増えるのは**背景1枚**だけで済むよう、版面はこの4種と同じに保つ。
- カードは **背景（この画像） → 選手スプライト → CSS の文字** の重ね順で組む。
- **動くホロは CSS で足す**（マスク + アニメーション）。背景画像は静止のままでよい。
  card-eleven はスクリム（暗幕）を弱めて背景イラストを透かしているので、同じ調整が要る
  （→ card-eleven `docs/08-card-design.md` §10.2）。
- 区画の座標は §2 の表がそのまま CSS の値になる。**背景を差し替えても文字は動かない**。
