# 選手カード デザインモック — 作成依頼（Gemini 向け）

このファイルをそのまま渡せば、選手カードのビジュアルモックを作れる。
**完成品はゲーム内で実行時に合成する**ため、ここで欲しいのは「そう見えるべき姿」の見本。
1枚ごとに絵を用意するのではなく、**レイアウトは固定・中身だけ差し替わる**前提で描いてもらう。

> 関連: 画面全体のデザインは [P-footBall.html](P-footBall.html)、
> トークンと画面仕様は [docs/06-design-system.md](../../../docs/06-design-system.md)。

---

## 1. 依頼文（ここから下をコピーして渡す）

スマートフォン向けサッカーゲーム「P-footBall」の**選手カード**のデザインモックを作ってください。

### 作品のトーン

- 暗色（ほぼ黒）の盤面に、**ゴールドを1色だけ**効かせたモダンで落ち着いた作り
- 選手の絵だけが色を持つ。装飾は最小限で、情報は整理されて見える
- レトロゲーム風の枠飾りやグラデーションの多用は**しない**。角丸は小さく、線は細く
- 参考の空気感: 現代的なスポーツアプリの UI ＋ コレクタブルカードの佇まい

### 出力してほしいもの

**縦長カード 4枚を横並びにした比較シート**（1枚ずつでも可）。
4枚は**レア度違い**で、レイアウトは完全に同一、色と発光だけが変わること。

- カード1枚の比率: **3 : 4（縦長）**。推奨サイズ 750 × 1000 px
- 背景（シートの地）: `#020306`
- カード同士の間隔は十分に空け、発光が隣に被らないこと

## 2. カードのレイアウト

**アートを全面に敷き、右側に縦一列のデータ列を重ねる**構成。
データ列は上に OVR、下に6能力を**下ぞろえ**で置く。こうすると数値が選手の絵と取り合わない。

```
┌────────────────────────────┐ ← 外枠 1.5px：レア度の色
│ ULTRA RARE           102   │ ← 左上:レア度 / 右上:OVR
│                            │
│                     ATK 17 │
│    [ピクセル選手]      DEF 18 │  アートは全面
│                     POW 15 │  データ列は右 28% に重ねる
│                     TEC 20 │
│                     SPD 18 │
│                     STA 14 │ ← 下ぞろえ
├────────────────────────────┤
│ G. リンドクヴィスト            │  名前帯（高さ 18%）
│ MF · OMF / CB · ノルディア     │
└────────────────────────────┘
```

### A. アート層（名前帯より上の全面）

- **選手はピクセルアート（ドット絵）**。上半身〜腰まで、正面向き、ユニフォーム姿。
  極端なデフォルメ（2〜3頭身）にはせず、写実にも寄せない中間のサイズ感。
  ドットの粒が見える解像度で、なめらかな補間をかけない（にじませない）。
- **選手は左寄せ**に置く。右28%はデータ列が乗るので、**顔と胴体がそこに掛からない**こと。
- 背景は**クラブカラーの斜めストライプ**。45度、`クラブ色` と `#10171f` を 6px ずつ交互。
  ストライプは主張しすぎず、選手が前に出ること。
- 選手の背後にごく淡い放射状の明かりを置き、シルエットを浮かせてよい。

### B. データ列（右 28% ・ 上端から名前帯まで）

数値の可読性を絵に依存させないため、**列の背後に暗いスクリムを敷く**。
右端に向かって濃くなる縦の帯（`#0e141d` の不透明度 0〜75% 程度）で、境界線は引かない。

| 位置 | 内容 | 指定 |
|---|---|---|
| 上端 | **OVR** `102` | 縦長コンデンス書体・極太・白・**カード幅の約22%と大きく**・濃い影 |
| 下端 | 6能力を縦に並べる | 下ぞろえ。行間は詰めすぎない |

能力の各行は `ラベル` と `数値` を**左右に振り分ける**。

```
 ATK        17
 DEF        18
 POW        15
 TEC        20   ← 20 に達した行だけゴールド
 SPD        18
 STA        14
```

- ラベルは等幅・小さめ・グレー `#78818c`
- 数値は等幅・白・ラベルの 1.5 倍程度・**右ぞろえ**（桁が揃って読める）
- **20 に達した能力だけ、ラベルも数値もゴールド `#e0af3b`** にする（上限到達の印）
- **バーは引かない**。小さく表示したときに潰れるため、数値だけで見せる

### C. レア度ラベル（左上）

`ULTRA RARE` を等幅フォント・太字・字間広め・**レア度の色**で。カード幅の約4%。
背後に絵が来るので、濃い影を落として読めるようにする。

### D. 名前帯（高さ 18% ・ 全幅）

アートの上に乗せず、**独立した暗い帯**（`#0e141d`）として最下部に置く。上辺に 1px の罫線 `#222933`。

| 行 | 内容 | 指定 |
|---|---|---|
| 1行目 | 選手名 `G. リンドクヴィスト` | 縦長コンデンス書体・太字・白（`#eeebe4`）・カード幅の約8% |
| 2行目 | `MF · OMF / CB · ノルディア` | 細字・グレー（`#78818c`）・カード幅の約4.5% |

2行目は「**メインポジション · サブポジション（複数） · 国籍**」の順。
サブポジションは `/` 区切りで、**先頭がプライマリ**。

## 3. レア度による違い（**ここだけが4枚の差**）

外枠の色・発光・ラベル文字色が変わる。**レイアウトと文字サイズは4枚とも完全に同一**。

| レア度 | ラベル | 枠と発光の色 | 発光の強さ |
|---|---|---|---|
| STANDARD | `STANDARD` | `#7c8186`（無彩色グレー） | ほぼ無し |
| RARE | `RARE` | `#2098db`（青） | 弱く |
| SUPER RARE | `SUPER RARE` | `#b48df4`（紫） | 中くらい |
| ULTRA RARE | `ULTRA RARE` | `#e0af3b`（金） | 強く |

- 発光は**カードの外側**へ柔らかく広がる（内側を光らせない）
- ULTRA だけ、アートにごく薄い箔のような光沢を斜めに一本入れてよい

## 4. 4枚に入れる実データ

**この文字列をそのまま描いてください**（架空の選手・クラブです）。

| | ULTRA RARE | SUPER RARE | RARE | STANDARD |
|---|---|---|---|---|
| OVR | `102` | `93` | `81` | `64` |
| 名前 | `G. リンドクヴィスト` | `A. シルヴェイラ` | `T. コワルスキ` | `H. コスタ` |
| 2行目 | `MF · OMF / CB · ノルディア` | `FW · ST / OMF · イベリア` | `DF · CB · エストラ` | `DF · RSB · イベリア` |
| クラブ色 | `#3b6fd4`（青） | `#d4643b`（オレンジ） | `#2fa88a`（緑） | `#8a5fd4`（紫） |
| ATK / DEF / POW | `17 / 18 / 15` | `20 / 9 / 18` | `11 / 17 / 15` | `9 / 13 / 11` |
| TEC / SPD / STA | `20 / 18 / 14` | `17 / 20 / 9` | `12 / 14 / 12` | `10 / 11 / 10` |

※ OVR は6能力の**合計**なので、上の数字を足した値になっています（各能力の上限は20、OVR の上限は120）。

---

## 5. やらないこと

- 実在の選手・クラブ・リーグの名前やエンブレムを出さない
- 写真・実写風の人物を使わない（**ピクセルアート**であること）
- 派手なグラデーション、光沢の多用、装飾的な枠飾り
- 文字を英語に置き換えない（**日本語はそのまま**、英字ラベルは英字のまま）
- 4枚でレイアウトを変えない（差はレア度の色と発光だけ）
- **選手の絵を右のデータ列に掛けない**（数値が読めなくなるため）
- 能力にバーやグラフを付けない（数値のみ）

## 6. 受け取ったあとの使い道（依頼先には不要）

- モックは**実装の目標**であって素材ではない。カードは実行時に
  「ピクセル選手 + 手続き的な枠」で合成する（選手は32クラブ×16人＋パックぶん生成される）。
- 現在の実装（[docs/06 §6.12](../../../docs/06-design-system.md)）との差分:
  - 今の一覧タイルは「アート + 下に名前・ポジション」の2段で、能力を出していない
    → この案では**カード1枚で能力まで完結**する。タイルの下段（名前・クラブ）はカードに畳める
  - 今のアートは `PLAYER PHOTO` のプレースホルダ → ピクセル選手に置き換える（実装バックログ第3段）
  - 小さく表示したとき（3列グリッドで幅120px前後）に能力の数値が読めるかは、
    モックを縮小して**必ず確認する**。読めなければ一覧では OVR だけ出し、能力は拡大時のみにする
- 気に入ったら `src/assets/design/` に画像を置き、docs/06 §6.12 を更新する。
